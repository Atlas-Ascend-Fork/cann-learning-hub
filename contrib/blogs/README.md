## 投稿说明

欢迎贡献与 Ascend/CANN 相关的技术博客与科研案例。投稿前请确保：

- 内容与 CANN/Ascend 技术相关，具备真实场景或实验数据支撑
- 结构清晰，包含背景、方法、实验与结论
- 代码可运行、路径相对化，说明完整
- **必须署名**：作者姓名、所在单位、联系方式

投稿方式请参考项目根目录的贡献指南，或通过 Issue/PR 与维护者联系。
