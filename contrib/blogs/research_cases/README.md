## 投稿指南

### 目录结构

每个案例放在独立文件夹中，结构示例：

```
contrib/blogs/research_cases/
├── your_case_name/
│   ├── README.md          # 案例正文（含作者信息）
│   ├── images/            # 图片资源
│   └── code/              # 可选：配套代码 / notebook
├── TEMPLATE/              # 投稿模板
└── README.md              # 本文件
```

### 署名要求

每个案例的 `README.md` **顶部必须包含作者元信息块**：

```markdown
# 案例标题

> **作者**：张三（XX大学 计算机学院）
> **协作**：李四（XX实验室）
> **单位**：XX大学 AI 计算团队
> **发布时间**：2026.09
> **关键词**：Ascend C / 算子优化 / 科研
```

### 内容要求

1. 内容与 CANN/昇腾科研相关，包含背景、方法、实验数据与结论
2. 图片统一放在 `images/` 目录，使用相对路径引用
3. 代码可运行、避免硬编码路径，使用相对路径或环境变量
4. Notebook 文件使用 UTF-8 编码，提交前请在本地验证可正常执行

### 审核流程

1. Fork 本仓库
2. 在 `contrib/blogs/research_cases/` 下创建您的案例目录（可参考 `TEMPLATE/`）
3. 提交 Pull Request 到 `cann/cann-learning-hub` 的 `master` 分支
4. 等待审核通过后合并
