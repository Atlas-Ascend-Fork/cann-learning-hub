# 开发者贡献参考实践

本目录用于存放**社区开发者贡献的参考实践案例**。与 `contrib/tutorials/` 侧重教学跟练不同，参考实践强调以真实场景为载体的端到端完整案例：从问题分析、方案设计到编码实现与性能调优，帮助读者建立工程化的开发视角。

## 与官方参考实践的关系

官方参考实践位于仓库根目录 `reference_practice/`，由维护者维护并随版本发布；本目录收录的案例由社区开发者贡献，经维护者评审后合入。两者定位一致，均要求：

- 端到端可复现：明确的输入、步骤与预期结果
- 工程完整性：源码、构建脚本与使用说明齐全
- 环境明确：标注开发验证所用的 CANN 版本与硬件平台

## 投稿说明

欢迎按以下要求贡献案例：

1. 在本目录下新建案例子目录（建议使用小写字母与下划线命名，如 `my_inference_case`）；
2. 子目录内提供 `README.md`，至少包含：案例简介、环境要求（CANN / 驱动 / 硬件）、目录结构、运行步骤、预期结果、常见问题；
3. 涉及模型与数据集的案例请说明获取方式与大小，避免提交大文件入库；
4. 代码需在所标注的环境上实际验证通过；
5. 通过 Issue / PR 提交并关联对应 Issue，评审通过后合入。

## 反馈与建议

若在使用案例过程中遇到问题，可通过以下方式反馈：

- 提交 Issue 至本仓库；
- 联系昇腾开发者社区技术支持。
