# GMRES 章节实践参考答案

Arnoldi 用 SpMV 生成新方向，Dot 求投影系数，AXPY 减去投影，Norm 和 Scale 将剩余向量归一化。

本题用 U2、单卡、MGS，对比 restart=4 与 30，其余求解参数相同。先确认两次收敛、真实残差不超过 `1e-6`、解误差小于 `1e-3`，再看迭代数与总时间。

两次输出的 Speedup=1 是各配置相对自身单 rank 的比值。配置间耗时比另算：现成结果 `10826/3733≈2.90`，同时迭代数从 36 变为 13，说明每步成本与收敛过程都要考虑。

当前 Notebook 读取 `api_statistic` 的 `Time(us)`、`op_statistic` 的 `Total Time(us)`，单位已是微秒，表内也已汇总，无需再换算或重新累加。`gmres_dot` 同时服务于 Dot 和 Norm 的平方和，Norm 的平方根在 Host 求；`gmres_scale`、`gmres_sub` 与 `gmres_axpy` 都归入应用 AXPY。分别观察 API、算子表中的主要条目；同步 API 的不同调用层次可能重叠，不把它们相加。

程序显示三次求解的单次均值，msprof 统计采集期间的累计量。每次 solve 仍有 RTC 和设备状态准备；Sync、Launch、Transfer 与阶段时间存在包含关系。
