# 9.2 参考答案

一次 Arnoldi 迭代可按以下顺序对应到计时字段：

1. 多卡时先清零全长设备向量，再将局部数据放入各自不重叠的区间。AllReduce SUM 将这些分片拼成完整向量，如 `[a,b,0,0]+[0,0,c,d]`；单卡跳过通信。
2. SpMV 计算新的搜索方向。
3. Dot 计算与已有基向量的投影，AXPY 减去这些分量；多卡时标量经 AllReduce 汇总。
4. Norm 和 Scale 将新方向归一化。
5. Host 用 Hessenberg 矩阵和 Givens 旋转更新小型最小二乘问题。

当前设备实现不使用 AllGather，其调用计数为 0。kernel launch 是主机提交开销，设备任务时间从 msprof 查看；API 时间与设备任务时间可能重叠，分别分析。
