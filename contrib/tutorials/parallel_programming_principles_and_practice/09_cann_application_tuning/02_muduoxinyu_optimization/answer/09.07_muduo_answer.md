# 9.7 MuduoXinyu 参考答案

## 基础理解

`functional_pass` 检查两种实现的 token、执行路径和 fallback；`performance_valid` 检查样本和工作量是否可比较；`performance_beneficial` 表示 B 的平均吞吐量在本次输入下高于 A。

A 使用 FP32 多算子，B 使用 FP16 FlashAttentionV4 和类型转换，比较的是两套完整实现。生成的 token ID 可以相同，中间浮点数会因精度和计算顺序不同而有差异。

## 运行与分析

设置源码、模型、tokenizer 和输出目录后运行脚本。查看 `result.json` 中的检查结果、A/B 平均吞吐量、波动和相对变化。脚本已自动检查 token 一致性、调用次数、fallback 和样本数量。

吞吐量变化为 `(mean_B / mean_A - 1) × 100%`。结果为负就按本次变慢分析；均值差异较小时，还要结合波动判断。

后续实验只改变一个条件，例如保持实现不变、交换运行顺序，或在相同精度下比较算子组织。若怀疑类型转换或启动开销，可用 profiler 继续查看。
