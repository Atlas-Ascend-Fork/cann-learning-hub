# 9.7 参考答案

残差为 b−Ax，反映当前解是否满足方程。restart 是一次重启前保留的搜索方向数；增大它通常增加存储和正交化工作，也可能减少重启次数。GMRES 外层小矩阵控制在 Host，SpMV/Dot/AXPY 等在设备端执行；Norm 复用设备 Dot 求平方和，再由 Host 开方。

KV cache 保存过去 token 的 Key 和 Value，避免重复计算。融合减少中间数据读写和提交次数。Muduo 的 A/B 同时改变算子组织和精度：A 为 FP32 多算子，B 为 FP16 FlashAttentionV4。

功能通过看 token 一致、执行路径和 fallback 检查；数据有效还要求工作量相同、样本齐全、吞吐量计算一致。两者通过后，才看 B 的平均吞吐量是否高于 A。均值相近时还要看波动，不能只凭一次运行下结论。

GMRES 单卡比较 restart=4 与 30，其余参数相同，记录迭代数、残差、解误差和 total。Profile 的 API 与算子统计表分别分析，注明来源。Muduo 按脚本完成 smoke A→B、performance B→A，各路径丢弃第一个预热样本，对后面三个样本求均值和变异系数。

相对吞吐量变化为 `(mean_B / mean_A − 1) × 100%`。结果为负就写本次变慢；功能正确但未加速仍是有效实验结果。没有要求复现某个固定百分比。
