# CANN 应用调优：讲稿与操作指南

杨怡雪讲 GMRES，傅俊林讲 MuduoXinyu，每人约 12 分钟：理论 6 分钟，演示与读结果 4 分钟，结论 2 分钟。

| 材料 | 用途 |
|---|---|
| [操作指南](operation_guide.md) | 在 CANNLab 打开 Notebook，准备、演示和关机 |
| [GMRES 讲稿](gmres_yang_yixue.md) | 理论、源码、结果分析；第 8 节可照读 |
| [MuduoXinyu 讲稿](muduoxinyu_fu_junlin.md) | Attention 原理、A/B 分析；第 8 节可照读 |

先读讲稿，再按操作指南彩排一遍。课堂操作使用仓库中的 Notebook，讲稿里的历史数据用于熟悉读数，录制时读本轮结果。

课前完成模型准备、依赖安装和编译。录制时从运行实验开始，等待期间解释参数和计算过程。结束后保存 Notebook 输出，并在平台关机。
