# 3.3 参考答案

总非零元数为 12，理想情况下每个进程分到 6 个。完整行之间可用的切分点对应累计数量 2、8、9；在第 2 行之前切分，得到 8 和 4，差距最小。

| 进程 | 行区间（从 0 编号） | 非零元数量 | 本地 row_ptr |
|---|---|---:|---|
| 0 | [0,2) | 8 | [0,2,8] |
| 1 | [2,4) | 4 | [0,1,4] |

进程 1 对应的全局边界是 `[8,9,12]`，每项减去起始偏移 8，得到 `[0,1,4]`。本地 values 和 col_idx 从自己的第 0 个元素开始，因此本地 row_ptr 也必须从 0 开始。第 1 行本身有 6 个非零元，不能在行内拆分时，两进程不一定能完全均分。
