# 4.3 参考答案

先创建 Runtime、设备 buffer 和 Tensor。每次执行都查询 workspace 与 executor，按查询结果准备 workspace，调用 `aclnnGemm` 并同步；本次 execute 结束后 workspace 自动释放。

预热和重复执行完成后，回读 output 并校验。退出函数时再释放 Tensor、设备 buffer 和 Runtime。workspace 为 0 表示本次不需要额外临时内存，查询步骤仍然执行。

本例没有开启 executor 复用，由框架管理其生命周期。参见[官方接口说明](https://www.hiascend.com/doc_center/source/zh/CANNCommunityEdition/910beta3/API/aolapi/operatorlist_00021.html)。
