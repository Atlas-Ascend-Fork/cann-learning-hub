# 2.2 参考答案

取矩阵 `A=[[2,0,3],[0,4,0],[5,0,6]]`，向量 `x=[1,2,3]`。

```text
row_ptr = [0, 2, 3, 5]
col_idx = [0, 2, 1, 0, 2]
values  = [2, 3, 4, 5, 6]
```

第 0 行：`2×1+3×3=11`；第 1 行：`4×2=8`；第 2 行：`5×1+6×3=23`。因此 `y=[11,8,23]`。

`row_ptr[r]` 和 `row_ptr[r+1]` 一起标出第 r 行的起止位置，因此需要 rows+1 个元素。最后一个值 5 等于非零元总数。
