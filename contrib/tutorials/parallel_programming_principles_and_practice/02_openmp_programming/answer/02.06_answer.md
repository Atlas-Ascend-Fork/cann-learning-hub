# 2.6 参考答案

## CSR 与按行并行

例如 `row_ptr=[0,2,3,5]` 描述 3 行，共 5 个非零元，最后一个边界等于 nnz。第 r 行只写 `y[r]`，各线程的输出位置不同，输入 x 共享但只读，因此按行并行不需要原子加法。

## 线程数比较

可复用 2.5 节的 1、2、4 线程 CSV；单独做练习时按题目命令运行，资源足够时再加 8 线程。每次都检查实际线程数和误差，使用同一行 CSV 中的串行时间除以 OpenMP 时间计算加速比；再除以线程数得到效率。

## 调度方式比较

固定矩阵、线程数和重复次数，对 U1、L1 分别测试 static 与 dynamic,16。U1 行长度较均匀，static 调度开销较小；L1 的长行可能使 static 负载不均，dynamic 能重新分配任务，但会增加调度开销。用本次耗时判断是否受益。

## 带宽与后续实验

CSV 的 `bandwidth_gbps` 是总估算带宽，除以实际线程数得到平均每线程估算带宽。该估算不能精确反映缓存命中。

可固定线程数和矩阵，只改变 dynamic 的块大小。若耗时随块大小明显变化，说明调度开销可能重要；若增加线程后总带宽趋稳且效率下降，可进一步用性能分析工具检查访存。一次对照只改变一个条件。
