# 6.7 参考答案

## 基础理解

1. row_ptr 标出每行在非零元数组中的起止位置；col_idx 保存列号；values 保存数值。
2. 每个旋转对处理 2 个通道，因此有 12×64÷2=384 对。
3. BF16 只把 values 从 4 字节降为 2 字节，32 位的 col_idx 和 row_ptr 不变。例如 4 行、8 个非零元：FP32 为 8×4+8×4+5×4=84 字节，BF16 为 8×2+8×4+5×4=68 字节。
4. position=0 时旋转角度为 0，输出应与输入一致。
5. kernel 提交是异步操作，Stream 同步完成后才能检查计算是否结束并读取结果。

## 手算与数据流

取矩阵 [[2,0,3],[0,4,0]]、向量 [1,2,3]，CSR 为 row_ptr=[0,2,3]、col_idx=[0,2,1]、values=[2,3,4]，结果为 [11,8]。Host 生成这些数组，复制到 Device，kernel 按行累加，再回读 y。

RoPE 对 (a,b) 计算 (a cosθ−b sinθ, a sinθ+b cosθ)。例如 (1,2)、θ=π/2 得到 (−2,1)。旋转保持这一对的平方和；实际浮点运算允许微小舍入误差。

## 实际运行

FP32 SpMV 检查实际后端、有限误差和 `1e-6` 阈值。RoPE 检查 4 个 position case 的误差与退出码。记录各自计时范围：SpMV 的 launch-to-complete 包含提交和同步，传输单列；不要把它当作纯 kernel 时间。

## 扩展实验

SpMV 分区试测属于 Host 原型，分别比较初始化和稳态成本。RoPE 调整参数后保留原来的 4 组正确性检查，再比较相同输入的时间。性能没有固定答案，说明本次输入、改动和测得的差异即可。A3 使用 SIMD/RTC 路径；950 SIMT 模板需对应硬件。
