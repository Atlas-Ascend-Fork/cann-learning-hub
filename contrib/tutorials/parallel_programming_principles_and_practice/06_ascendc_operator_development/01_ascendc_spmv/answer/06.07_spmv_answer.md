# 6.7 SpMV 参考答案

## 基础题

（1）`ascend_c`。（2）`AscendCSpmvBackend`。（3）从 Kernel 提交到 Stream 同步完成，包含提交与等待执行的时间。

## 读取结果

`cold_start` 表示一次性初始化，包含格式转换、分区试测和缓冲区准备。`warm total` 表示复用数据后每次调用的总时间。压缩比用 FP32 字节数除以低精度字节数；balance 描述分区工作量差异；error 表示与参考结果的误差。

CPU 原型使用 `host_prototype_*` 字段，设备实现使用 `ascendc_*` 字段。结合实际调用和 `Actual Backend` 日志确认位置。

## 单变量比较

只改变分区候选数或精度，保留同一输入与重复次数。先看误差，再看初始化和计算时间；增加候选可能花更多试测时间，改变精度则同时影响存储和数值误差。用本次数据解释取舍。

## 追踪执行

FP32 设备实现调用 `aclrtMalloc`、`aclrtMemcpy`，通过 RTC 编译和加载 Kernel，随后启动、同步并回读结果。CPU 原型在主机循环中计算。相同的后端接口可以调用不同实现，但性能比较仍需注明执行位置和计时范围。
