# 6.4 参考答案

设初始化时间为 C，每次复用后的总时间为 W，则调用 N 次的成本约为 `C+N×W`：

- 1 次：`C+W`。
- 10 次：`C+10W`。
- 1000 次：`C+1000W`。

平均每次成本为 `W+C/N`。完成 6.5 节后，把本次测得的 `cold_start` 和 `warm total` 代入。初始化包括格式转换、分区试测和缓冲区准备，不含第一次正式计算；要测首次完整延迟，应记录初始化加第一次 run 的时间。

普通 BF16 和 persistent 原型还使用了不同的并行条件。这里的成本分摊使用同一 persistent 实现的初始化与重复计算时间，不从两套实现的差值单独推算复用收益。
