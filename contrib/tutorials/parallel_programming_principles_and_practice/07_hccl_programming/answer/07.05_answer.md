# 7.5 参考答案

记录设备数、通信、传输、本地 SpMV、总时间和误差。本地 SpMV 的 `local_spmv_launch_to_complete_ms` 包含提交和同步等待，Synchronization 已包含在其中。

汇总先取每轮各 rank 的最大值，再对轮次求平均；各阶段最慢的 rank 可能不同，阶段时间不必相加等于 total。

多卡比较时固定矩阵和重复次数，用同参数的 1 rank 总时间除以多 rank 总时间计算加速比，再除以 rank 数得到效率。只有单卡时先完成数据流检查，列出多卡对照需要测量的项目。运行脚本会打印本次日志目录，保存其中各 rank 的日志。
