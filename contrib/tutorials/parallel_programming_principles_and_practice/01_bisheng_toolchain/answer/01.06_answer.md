# 1.6 参考答案

`clang++` 用于 Host C++ 程序；本课程的 Host 编译要求版本输出带 BiSheng 标识。CANN 的 `bisheng` 用于 Ascend C 源码，目标架构应从实际产品与工具帮助中确认。

从本章目录执行 `mkdir -p results`，再执行 `clang++ -std=c++17 -O2 src/hello_host.cpp -o results/hello_host` 和 `./results/hello_host`。成功输出 `host toolchain ready`，退出码为 0。查看本次程序输出。

源文件名写错时，编译器在编译阶段报告文件不存在，尚未生成本次程序。改回正确名称后重新编译运行；不要误运行以前留下的产物。

`hello_world.asc` 中的 main 没有启动 kernel。编译通过只能说明源码和编译环境可用；要确认 Device 执行，还需要 Host 分配资源、提交 kernel、同步并校验结果，后续章节会完成这些步骤。
