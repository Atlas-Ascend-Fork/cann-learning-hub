# 1.5 参考答案

| 实验 | 主要工具与库 | 设备 |
|---|---|---|
| OpenMP | 鲲鹏毕昇 `clang++`、CMake、OpenMP | CPU |
| MPI | `mpicxx`、`mpirun`、MPI 头文件和库 | CPU |
| ACL C++ | C++ 编译器、CANN；SpMV 还需 ops-sparse | NPU |
| ACL Python | Python、NumPy、pyACL、ATC | NPU |
| Ascend C | CANN 编译工具和运行时 | NPU |
| HCCL | CANN、HCCL；多卡时需通信配置 | 单卡或多卡 NPU |
