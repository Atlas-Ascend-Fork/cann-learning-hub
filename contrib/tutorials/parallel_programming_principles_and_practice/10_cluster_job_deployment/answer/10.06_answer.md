# 10.6 参考答案

本章从 `src/ascend_xyce` 编译并运行三种求解器，保存日志和 CSV。CPU 实现随本章提供，设备求解器使用第 09 章的 GMRES，因此需要保留完整课程目录。

## 一、基础题

1. A。三种求解器是 `CpuSingle`、`CpuOpenMP16` 和 `AscendDevice`。
2. 对。CMake 的 `xyce_npu_solver` 编译第 09 章 `dis_gmres`；适配器调用 `dis_gmres::distributed_gmres`。本章附带的 `backend/gmres/Ascend-GMRES` 提供 CPU 实现和旧 Host 原型。
3. B。CSV 有一行表头，每个矩阵对应三行求解结果。未知矩阵名在打开 CSV 前被拒绝，程序返回 2；运行结束还会检查数据行数。
4. 对。本章运行的是线性求解器测试程序，用于比较求解结果和耗时。完整电路仿真还需要 Xyce 读取电路网表并执行仿真。

## 二、运行与校验

按章测命令构建并运行 U1，保存本次日志和 CSV。检查三行结果：

- `converged=1`，`final_residual` 为有限数且不超过 `1e-6`。
- `solution_error_vs_expected` 为有限数且不超过 `1e-3`。
- OpenMP 和 Device 的 `solution_error_vs_cpu` 为有限数且不超过 `1e-3`；CPU 行的 0 表示与自身比较。

记录求解器、实际迭代数、残差、解误差和耗时。时间填写本次测量值，没有固定答案。

## 三、解释耗时和错误

矩阵装配是准备线性方程，线性求解是计算解向量，SpMV 是求解过程中的一个步骤。先看各字段包含的范围：总时间已经包含求解时间，求解时间又包含 SpMV，不能把三者重复相加。

用未知参数做一次失败实验，保存错误输出。区分找不到参数、构建失败、设备初始化失败和结果文件无法写入，再指出该回到哪一步处理。
