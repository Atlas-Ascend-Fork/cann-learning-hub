# 传统课程 · 《现代电子技术基础》：课程大纲

> 本文件为《现代电子技术基础》（人工智能专业基础课 · 40 学时）**单课程落地文件**；总规划见本目录 [README.md](./README.md)。
> 课程定位：**传统电子技术主体 + 前沿拓展单元**——电路 / 模电 / 数电 / 数模混合四大传统主体（36 学时）打底，第 5 部分"**前沿拓展——AI 芯片与 NPU 认知**"（● 4 学时主讲 + 2 学时上机）把课堂上的每一个电路与器件知识点，映射到真实 AI 芯片（昇腾 NPU）上——**"模电数电学的不是分立元件，是 AI 芯片的物理底座"**。
> 融入方式：M2 前沿拓展单元（●）＋ 贯穿各章的 ◐ 昇腾对照卡（功耗 ↔ 能效、SRAM ↔ 多级存储、加法器 ↔ Cube 阵列、量化 ↔ 低比特计算等），对照卡在前沿拓展单元汇成完整 NPU 架构图。

## 二、课程目标与内容规划

### 2.1 三维目标

| 目标维度 | 达成要求 |
|---------|---------|
| **知识目标** | ① 掌握电路分析基本方法（基尔霍夫定律 / 戴维南等效 / 一阶动态电路）与半导体器件（二极管 / BJT / MOSFET）原理；② 掌握放大电路、负反馈、运算放大器与电源管理的分析与估算方法；③ 掌握组合 / 时序逻辑设计、存储器与可编程逻辑基础，理解 ADC/DAC 指标与数模混合系统设计要点；④ 建立 AI 芯片认知：达芬奇架构三核异构、多级存储体系、功耗与能效、低比特量化 |
| **能力目标** | ① 能用仿真工具（Multisim/LTspice/Logisim）分析验证典型电路；② 能完成中小规模组合 / 时序逻辑（含状态机）设计；③ 能解读 ADC/DAC 数据手册关键指标；④ 能用 npu-smi 查询并解读昇腾 NPU 硬件规格，完成 CPU vs NPU 性能对比 |
| **素养目标** | 建立"**底层电路 → 芯片架构 → AI 系统**"的贯通视角——理解 AI 算力的物理基础（晶体管、功耗、存储、量化），破除"AI 是纯软件"的认知局限 |

### 2.2 结业能力画像

完成本课程后，学员将能够：

- **算得出**：用戴维南等效、三要素法、微变等效模型手算典型电路，用仿真工具验证；
- **搭得出**：设计组合 / 时序逻辑电路与有限状态机，读懂 Verilog 入门代码；
- **读得懂**：解读 ADC/DAC 与运放数据手册的关键指标（分辨率 / 采样率 / ENOB / GBW）；
- **对得上**：把课堂每个电路知识点映射到真实 AI 芯片——SRAM ↔ UB/L1/L0、CMOS 功耗 ↔ TOPS/W、量化 ↔ INT8/FP8、信号链 ↔ 数据搬运流水；
- **查得到**：用 npu-smi 查出真实 NPU 的 AIC/AIV 核数、UB/L1 容量，并与本课 SRAM 计算结果对照验证。

### 2.3 课程内容规划（五部分）

| 部分 | 学时 | 内容主线 | CANN 深度 |
|------|:---:|---------|:---:|

## 三、前置内容

### 3.1 知识前置（硬性要求）

| 类别 | 要求 |
|------|------|
| 数学基础 | 微积分（暂态电路求解）、复数与相量（频率响应）、线性代数（矩阵基础，前沿拓展衔接） |

- **NPU 环境**：前沿拓展上机使用 [CANNLab](https://gitcode.com/org/cann/cannlab) 云端环境（注册即赠 100 卡时，无需本地硬件），课前建议浏览 [quick_start/cann_basics](../../quick_start/cann_basics/)（约 30 分钟）。

## 四、教学安排与理论讲义（PPT）

> 全课 15 讲 × 2 学时 + 仿真实验 3 × 2 学时 + NPU 上机 4 学时 = 40 学时——第 1~4 部分按章合并呈现（每章一行，合计 14 讲），第 5 部分逐讲列出（1 讲 + 上机）。CANN/昇腾融入采用 **○ 提及 / ◐ 对照 / ● 主讲** 三档深度。

### 4.1 第一部分 电路与半导体基础（8 学时理论 + 实验 2 学时，共 10 学时）

| 章节 | 内容要点 | CANN/昇腾融入点 |
|------|---------|----------------|
| 电路与半导体基础 | **电路定律与分析**：电压 / 电流 / 功率参考方向、基尔霍夫定律、电阻网络等效（串并 / Δ-Y）、节点电压法 / 网孔电流法、戴维南 / 诺顿等效、最大功率传输；**一阶动态电路**：RC/RL 零输入 / 零状态 / 三要素法；**半导体器件**：本征 / 杂质半导体、PN 结、二极管模型与应用（整流 / 稳压 / 限幅）、BJT 三个工作区、MOSFET 伏安特性；**CMOS 与集成工艺**：反相器逻辑摆幅、静态 / 动态功耗 P=αCV²f、传播延迟、工艺缩放与摩尔定律、先进封装一瞥 | ○ 功率与效率 → NPU TOPS/W 能效一瞥；◐ 一阶 RC 暂态 → 存储访问延迟与流水线节拍的电路根源；○ 晶体管开关 → NPU 数百亿晶体管叙事；◐ CMOS 动态功耗公式 → 功耗墙与能效（前沿拓展总回响） |

### 4.2 第二部分 模拟电子技术（6 学时理论 + 实验 2 学时，共 8 学时）

| 章节 | 内容要点 | CANN/昇腾融入点 |
|------|---------|----------------|
| 模拟电子技术 | **放大电路基础**：共射 / 共源放大、静态工作点估算与稳定（分压偏置）、微变等效模型、增益 / 输入输出电阻、非线性失真、频率响应、多级耦合；**差分放大与负反馈**：差模 / 共模与 CMRR、恒流源偏置、四种反馈组态与深度负反馈近似；**运放与电源**：虚短 / 虚断、同相 / 反相 / 加减 / 积分电路、有源滤波器、比较器、甲乙类功放、LDO 与 DC-DC 电源管理 | ○ 放大即信号能量受控转换 → 芯片信号链模拟前端；◐ 差分对称结构 → 高速接口（SerDes）差分信号基础；◐ 电源管理 → AI 加速卡板级供电与功率密度（功耗墙板级视角） |

### 4.3 第三部分 数字电子技术（8 学时理论 + 实验 2 学时，共 10 学时）

| 章节 | 内容要点 | CANN/昇腾融入点 |
|------|---------|----------------|
| 数字电子技术 | **数制与逻辑代数**：二进制 / 十六进制、原码 / 反码 / 补码、格雷码 / BCD、逻辑代数定理与卡诺图化简；**组合逻辑**：编码器 / 译码器 / 数据选择器、半加 / 全加 / 超前进位加法器、竞争与冒险；**时序逻辑**：RS / D / JK 触发器、寄存器与移位寄存器、同步 / 异步计数器、建立 / 保持时间与最高时钟频率；**存储器 / 可编程逻辑 / 状态机**：SRAM 六管结构、DRAM / Flash 基础、容量-速度-功耗权衡、FPGA / CPLD 架构、Verilog 一瞥、Moore / Mealy 状态机设计流程 | ○ 补码与定点表示 → AI 低比特数值（INT8/FP8）伏笔；◐ 超前进位加法器 → NPU Cube 矩阵引擎乘加树与脉动阵列；◐ 触发器时序约束 → NPU 流水线节拍与同步设计；◐ SRAM → NPU 多级存储体系（GM→L1→L0A/B/C→UB），本课 SRAM 计算即其物理基础 |

### 4.4 第四部分 数模混合与系统综合（6 学时）

| 章节 | 内容要点 | CANN/昇腾融入点 |
|------|---------|----------------|
| 数模混合与系统综合 | **ADC 原理与指标**：采样定理与抗混叠、量化噪声 / ENOB / SFDR、SAR / 流水线 / Σ-Δ 架构对比（速度-精度-功耗三角权衡）；**DAC 与信号链设计**：DAC 架构（权电阻 / R-2R / 电流舵）、建立时间与毛刺、完整信号链综合（传感器 → 放大 → 滤波 → ADC → 数字处理 → DAC 输出）；**数模混合系统设计**：信号完整性（串扰 / 反射）、电源与地平面（去耦电容布局）、时钟分布与 PLL、SoC 集成概览；**综合案例**：从图像传感器信号链到数字处理——把第 1~4 部分知识串成一条链 | ◐ 量化与 ENOB → AI 低比特计算（INT8/FP8），量化即"芯片化的模数转换"；◐ 模拟信号链 → NPU 数据搬运流水（MTE），一条数据从物理世界到算子的完整旅程；◐ SoC 模拟 IP（PLL / SerDes / 温度传感器）→ 真实 AI 芯片（昇腾）中的混合信号设计；◐ "信号链思维"收束 → 前沿拓展导入 |

### 4.5 第五部分 前沿拓展——AI 芯片与 NPU 认知（1 讲 + 上机 4 学时，共 6 学时，● 主讲单元）

> 主线：**映射（电子技术知识如何落到 AI 芯片）→ 实测（CANNLab 上与真实芯片对账）**。教材 PPT：**待开发**（内容要点与"本课知识 → NPU 映射总表"如上表所列）。

| 讲次 | 主题 | 内容要点 | 教材 PPT |
|------|------|---------|---------|
| 15 | 电子技术视角的 NPU 与 CANN 生态 | **本课知识 → NPU 映射总表**：SRAM ↔ UB/L1/L0、CMOS 功耗 ↔ TOPS/W、加法器 ↔ Cube 乘加树、触发器时序 ↔ 流水线节拍、量化 ↔ INT8/FP8、信号链 ↔ MTE 搬运（每条映射配一句架构背景，达成 NPU 认知级理解）；CANN 软件栈全景一瞥（对上适配框架 / 对下驱动芯片）；Ascend C 编程模型一瞥；npu-smi 硬件查询实践 | **待开发**（以"本课知识 → NPU 映射总表"为主线开发） |
| 上机 | CANNLab NPU 认知实践（4 学时） | ① CANNLab 注册与首次上机；② **npu-smi info 查询 AIC / AIV 核数与 UB / L1 容量**（与实验 1 及第三部分 SRAM 计算对照验证）；③ CPU vs NPU 矢量计算性能对比体验（直观感受"专用架构"收益）；④ 当堂完成 NPU 认知报告初稿（规格解读 + 对比数据 + 电路知识对照） | CANNLab 云端环境 |

> **对照卡收束设计**：第 1~4 部分每章埋入的 ◐ 对照卡（共约 8 张：功耗 / 暂态 / 差分 / 电源 / 补码 / 加法树 / 时序 / SRAM / 量化 / 信号链），在第 15 讲汇成"**本课知识 → NPU 映射总表**"——同体系结构课"三幕剧"的收束模式，物理课堂的电路图最终落到真实 AI 芯片上。

## 七、学习建议

- **第 1~4 部分"攒卡"**：每学一个电路知识点，顺手记一张 ◐ 昇腾对照卡（SRAM ↔ UB、功耗 ↔ TOPS/W……），第 5 部分的"映射总表"就是这些卡片的总装；
- **仿真先行**：所有电路先手算再仿真验证，"手算 ↔ 仿真"对账是电子工程师基本功（对应 CANN 社区"预测先行 → 实测对账"的调优方法论）；
- **带着问题上前沿课**：第 15 讲（前沿拓展）前自问"我学的晶体管、SRAM、触发器、ADC 去了 AI 芯片的哪里"——每次课都问一句"为什么这样设计、代价是什么"；
- **上机对账**：实验 4 用 npu-smi 查出的 UB/L1 容量，与实验 1 和第三部分课堂的 SRAM 参数对照——**物理课堂的数字和真实芯片的数字对上号，是本课最有成就感的时刻**；
- **学有余力**：完成前沿拓展后可衔接 [01_ascendc](../00_atomic_courses/04_ops_programming/01_ascendc/) 系列讲义与 [quick_start](../../quick_start/) 教程，从"读懂芯片"走向"用 Ascend C 驱动芯片"。
