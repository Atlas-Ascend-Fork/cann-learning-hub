# 《AI 背后的中国芯——国产 AI 芯片与智能计算》课程大纲

> **V3 润色定稿**：依据《AI背后的中国芯——国产AI芯片与智能计算》课程教学大纲.docx（盛淑然等编）与通识课润色定稿重排——课序按**四模块逻辑主线**组织（AI 浪潮 → 算力底座 → 行业与格局 → 挑战未来），原第 3/4 章内容重叠已消除（达芬奇架构与昇腾谱系统一移入第 4 次课，第 3 次课聚焦通用算力概念）。
> 课程定位：传统课程目录"**换芯不换课**"整课共建——重理解、轻代码，重体验、重思辨，**不涉及底层编程与算子开发**；校企联合授课，课程思政要素融入第 6/7/8 次课（科技向善、产业自主、青年责任）。
> 实践环境"可上网的机房即可"：GitCode 在线 Notebook（NPU + CANN 预集成镜像，免费）+ 华为云 ModelArts + 昇腾社区 + Coze 智能体平台，零安装零配置。

## 一、课程基本信息

| 项目 | 内容 |
| ---- | ---- |
| **课程类型** | 通识教育核心课（AI 素养与科技认知类） |
| **适用对象** | 本科各专业（非计算机类为主），零基础 |
| **学时学分** | 16 学时 / 8 次课（每次 2 学时），建议 1 学分 |
| **先修要求** | 无——不涉及底层编程与算子开发 |
| **授课学期** | 2026–2027 学年第 2 学期 |
| **课程团队** | 盛淑然、任菊慧、待定/华为技术有限公司（校企联合授课，企业导师带实践） |
| **实践环境** | 可上网的机房即可；GitCode 在线 Notebook（NPU + CANN 镜像）、华为云 ModelArts、昇腾社区、Coze 智能体平台；部分体验可在手机/平板完成 |
| **教学方式** | 案例讲授 + 一键运行体验 + 方案研讨，强调"理解、会用、能思辨" |

## 二、逻辑主线

一句话：**从"看得见的 AI"，到"看不见的算力"，再到"中国芯的位置与未来"。**

| 模块 | 课次 | 核心问题 |
| ---- | ---- | ---- |
| 模块一：AI 浪潮与应用形态 | 第 1—2 次 | AI 现在能做什么？如何从大模型走向智能体？ |
| 模块二：算力引擎与国产底座 | 第 3—5 次 | 算力为何关键？昇腾 + CANN 如何构成中国芯底座？ |
| 模块三：行业赋能与产业格局 | 第 6—7 次 | AI 用在哪里？全球算力竞争格局如何？ |
| 模块四：挑战与未来 | 第 8 次 | 国产算力还缺什么？未来走向何方？ |

## 三、课程目标

- **知识目标**：理解大模型、生成式 AI、智能体的基本概念，建立"数据—算法—算力"三位一体的认知框架，了解昇腾芯片与 CANN 软件栈的定位与关系。
- **能力目标**：能用零代码平台体验 AI 应用，能在昇腾算力上完成一次大模型一键部署与对话测试，能对 AI 产业事件做初步分析。
- **素养目标**：形成对国产 AI 芯片与智能计算生态的客观认知，增强科技自信、数据安全意识和科技向善的责任感。

## 四、8 次课详细大纲

### 第 1 次课：大模型与生成式 AI——AI 浪潮的现在时
| 项目 | 内容 |
| ---- | ---- |
| **核心问题** | 人工智能为什么突然"会写、会画、会对话"了？ |
| **教学要点** | ① AI 发展简史：图灵测试 → 专家系统 → 深度学习 → 生成式 AI；② AI 三要素：数据、算法、算力；③ 生成式 AI 能力图谱：文本、图像、音频、视频、代码；④ 主流大模型概览：GPT、Gemini、DeepSeek、Qwen、豆包等；⑤ 能力边界：幻觉、时效性与可信度 |
| **体验互动** | "AI 初体验"：用对话工具写自我介绍、生成主题图片；辨别 AI 输出的可信度 |
| **形式** | 讲授 + 演示 + 动手体验 |

### 第 2 次课：从大语言模型到 AI 智能体——从"会对话"到"会做事"
| 项目 | 内容 |
| ---- | ---- |
| **核心问题** | 大模型和智能体有什么区别？AI 如何自主完成任务？ |
| **教学要点** | ① 大模型是"大脑"，智能体是"大脑 + 记忆 + 手脚（工具）"；② 智能体能力链：理解意图 → 任务规划 → 工具调用 → 执行操作 → 反馈迭代；③ 从生成式 AI 到 Agentic AI 的趋势；④ 行业案例：金融外呼、设备运维、办公助手；⑤ 具身智能初探：智能体走进机器人 |
| **体验互动** | 在 Coze 等平台创建简单任务型智能体，观察任务拆解与工具调用；讨论"智能体会改变哪些工作" |
| **形式** | 讲授 + 平台实操 + 小组讨论 |

### 第 3 次课：AI 的发动机——算力与异构计算
| 项目 | 内容 |
| ---- | ---- |
| **核心问题** | 为什么 AI 离不开专门的计算芯片？ |
| **教学要点** | ① 大模型训练 / 推理的算力需求有多大（量级感受）；② CPU、GPU、NPU 的分工："全能选手 vs 专项选手"；③ 异构计算：让不同计算单元各司其职；④ 算力基础设施：数据中心、超算、云计算、超节点；⑤ 算力度量：FLOPS、显存 / 内存、互联带宽（概念性） |
| **体验互动** | 观看芯片架构动画；对比同一任务在 CPU / NPU 上的耗时（cann-learning-hub 在线 Notebook 一键运行）；讨论"没有 AI 芯片，手机和数据中心会怎样" |
| **形式** | 讲授 + 可视化演示 + 类比互动 |

### 第 4 次课：硬件昇腾、软件 CANN——算力底座的一体两面
| 项目 | 内容 |
| ---- | ---- |
| **核心问题** | 中国芯的"硬件"和"软件"如何协同工作？ |
| **教学要点** | ① 硬件面：昇腾 AI 芯片与达芬奇架构——Cube、Vector、Scalar 三大计算单元，昇腾芯片谱系；② 软件面：CANN 是连接芯片与框架的"翻译官"，分层架构（应用层、图引擎、算子库、Runtime）；③ 软硬协同：兼容 PyTorch、MindSpore 等主流框架；④ 一体两面的意义：好芯片要靠好软件才能释放算力；⑤ 昇腾 + CANN 在国产 AI 生态中的位置 |
| **体验互动** | 解读软硬协同架构图；在 Notebook 中查看 CANN 版本与设备信息（`quick_start/cann_basics/02_what_is_npu` / `03_what_is_cann`）；讨论"为什么有了好芯片，还需要好软件" |
| **形式** | 讲授 + 架构图解读 + 互动 |

### 第 5 次课：CANN 开源生态与开箱即用——亲手部署一个大模型 ⭐ 课程高光
| 项目 | 内容 |
| ---- | ---- |
| **核心问题** | 非计算机专业学生，也能部署大模型吗？ |
| **教学要点** | ① 为什么开源开放：授人以渔、生态共建；② CANN 开源了什么：源码仓、模型库、样例、工具与商用最佳实践；③ 里程碑：昇腾成为 PyTorch 官方支持的**首个中国硬件**，torch_npu 开源；④ 开箱即用：在线 Notebook、预置镜像、模型库；⑤ 部署流程：选模型 → 配算力 → 启动服务 → 对话测试（概念性，不写代码） |
| **核心练习** | **一键部署大模型**：在 GitCode NPU Notebook（CANN 镜像，载体 `quick_start/first_llm_inference/01_qwen3_npu_inference_baseline.ipynb`）或 ModelArts 上，选择预置大模型（Qwen / DeepSeek 等）启动推理服务，通过 Web 界面完成对话测试，观察资源占用与部署日志。全程不写代码，助教辅助 |
| **形式** | 讲授 + 一键部署实操 + 成果展示 |

### 第 6 次课：AI 赋能千行百业——行业应用与 AI for Science
| 项目 | 内容 |
| ---- | ---- |
| **核心问题** | AI 如何在真实行业中创造价值？ |
| **教学要点** | ① AI + 医疗：影像筛查、辅助诊断、健康助手；② AI + 金融：智能风控、客服、信贷尽调；③ AI + 制造：智能质检、预测性维护、数字员工；④ AI + 教育、交通、能源概览；⑤ AI for Science：科学大模型、蛋白质结构、材料筛选、气象预测；⑥ 落地共性：数据质量、行业知识、安全合规 |
| **体验互动** | 分组分析一个行业场景的价值与风险；用 AI 工具完成行业相关小任务 |
| **形式** | 案例讲授 + 分组研讨 + 工具体验 |

### 第 7 次课：AI 芯片产业格局与算力竞争——全球视野下的中国芯
| 项目 | 内容 |
| ---- | ---- |
| **核心问题** | 全球算力之争究竟在争什么？中国芯处于什么位置？ |
| **教学要点** | ① 主要玩家：英伟达、AMD、英特尔、谷歌 TPU、华为昇腾、寒武纪等；② 竞争维度：芯片性能、软件生态、开发者规模、制程、能耗；③ 生态壁垒：CUDA 为什么成功，ToB / ToD 的生态逻辑；④ 出口管制与国产替代：算力自主可控为何重要；⑤ 算力基础设施竞争：数据中心、超节点、云算力 |
| **体验互动** | 绘制全球 AI 芯片格局简图；辩论"国产 AI 芯片最大的短板是硬件还是生态" |
| **形式** | 讲授 + 辩论 + 产业分析 |

### 第 8 次课：国产 AI 算力的挑战与未来——技术、生态与责任
| 项目 | 内容 |
| ---- | ---- |
| **核心问题** | 国产 AI 算力还缺什么？未来走向何方？ |
| **教学要点** | ① 技术挑战：性能、制程、能耗与散热；② 生态挑战：软件栈成熟度、开发者习惯、框架兼容性；③ 应用挑战：落地成本、数据安全、人才缺口；④ 未来趋势：多模态、AI Agent、具身智能、绿色算力、超节点；⑤ 科技向善与青年责任：如何参与社区、认证、赛事与开源贡献 |
| **体验互动** | 小组"AI + 本专业"方案或国产算力观察报告汇报、同伴互评；全景复盘"数据—算法—算力—芯片—生态"知识链 |
| **形式** | 方案展示 + 同伴互评 + 教师点评 |

## 五、考核方式

| 考核项目 | 占比 | 说明 |
| ---- | ---- | ---- |
| 课堂参与与互动 | 20% | 出勤、讨论、平台实操参与度 |
| 实践任务作业 | 30% | 含第 5 次"一键部署大模型"、智能体体验、行业案例分析（按易/中/难分层给分，评"观察—记录—解释"不评编程） |
| 产业观察短文 | 20% | 围绕 AI 芯片或算力竞争撰写约 600 字分析 |
| 小组方案展示 | 30% | 第 8 次汇报"AI + 本专业"构想或国产算力观察报告（**为方案 / 报告，非开发项目**） |

## 六、教学建议

1. **黑盒化、类比化**：把大模型和芯片架构当"黑盒"，用类比、动画、架构图降低门槛；
2. **突出亮点练习**：第 5 次"一键部署大模型"是课程高光环节，建议配备助教全程辅助；
3. **差异化案例**：文科侧重 AI 写作与内容创作，经管侧重决策与金融，理工侧重 AI + 本专业，医学侧重辅助诊断；
4. **动态更新**：AI 芯片与 CANN 生态迭代快，每学期更新产业案例与数据；
5. **设备要求**：能上网的机房即可，部分体验可在手机 / 平板上完成；
6. **校企协同**：企业导师参与第 4、5、7 次课（架构、部署、产业格局），实践环节由企业提供云端算力额度。
