# 《数字系统设计》课程大纲

> 本文件为《数字系统设计》课**单课程落地文件**（传统课程目录·数字系统设计）；总规划见本目录 [README.md](./README.md)。
> **课程定位**：数字系统设计课程的 DNN 加速融入版——第一部分以**硬件视角**讲透 DNN 算法与量化（每个算法都回答"它要硬件做什么"），第二部分用 **Ascend C 在 NPU 上兑现算法收益**（矩阵编程 → 卷积与注意力 → 量化加速），第三部分以 `quant_matmul` 结业大作业收口。算法选硬件、硬件反哺算法的**协同设计观**贯穿全程。
> **三部分结构**：第一部分 DNN 算法基础与量化（4 次课 × 3 课时）→ **第二部分 Ascend C 加速 DNN 核心计算（3 次课 × 3 课时 = 9 课时）**：Tensor API 矩阵编程 → 量化（含 **NPU 量化详细介绍与 fp4 实践案例**，铺垫结业 `quant_matmul`）→ 卷积与注意力（含 **NPU 卷积详细介绍**）→ 第三部分实践与内容拓展。
> **课程衔接**：建议先修《现代体系结构》（提供 NPU 架构背景）；本课程独立成纲、自身闭环。第二部分参考讲义为 [05_npu_architecture](../00_atomic_courses/04_ops_programming/05_npu_architecture/) 三份 PPT 与 [01_ascendc](../00_atomic_courses/04_ops_programming/01_ascendc/) 原子课程。

## 二、课程目标与课程内容规划

### 2.1 三维目标

| 目标维度 | 达成要求 |
|---------|---------|
| **知识目标** | ① 掌握 DNN 基础架构与计算特征（算子族、计算密度、算力 vs 访存）；② 掌握 CNN 与 Transformer 的算法细节及各自硬件诉求；③ 掌握 DNN 量化原理（per-channel / MX 缩放、QAT / PTQ）与模型压缩方法（剪枝 / 蒸馏 / 硬件感知优化）；④ 掌握 Ascend C Tensor API 矩阵编程模型与 NPU 上卷积、注意力、量化的加速原理 |
| **能力目标** | ① 能定量估算 DNN 计算量 / 访存量与量化收益（Roofline 直觉、位宽红利）；② 能基于 Tensor API 独立实现矩阵算子（GEMM）并在其上完成卷积、量化矩阵乘实现与改造；③ 能用 Tiling / 布局 / 融合手段优化算子，并用 profiling 数据与微结构原理解释每一处变化 |
| **素养目标** | 建立"算法 → 硬件"协同设计观：算法选择决定硬件效率、硬件特性反哺算法选择；具备"先算账、再动手"的定量工程习惯 |

### 2.2 结业能力画像

完成本课程后，学生将能够：

- **算得清**：给定一个 DNN 模型，估算其计算量、访存量与 INT8 量化的收益（第一部分方法）；
- **讲得透**：说清 CNN / Transformer / 量化各自的算法原理与对 NPU 的核心诉求（局部复用、全局注意力、缩放因子通路）；
- **编得出**：基于 Ascend C Tensor API 独立实现 GEMM，并扩展完成卷积与量化矩阵乘（`quant_matmul`）；
- **优化得动**：通过 Tiling / 布局 / 融合改造算子性能，每一步都有 profiling 数据与原理依据；
- **衔接得上**：从算法课的知识到大作业的工程闭环，一路有产出物为证。

## 四、教学安排

### 第一部分：DNN 算法基础与量化（12 课时 · 4 次课，硬件视角）

> 本部分定位：**给数字系统设计学生的算法课**——每个算法主题都落到"它要硬件做什么"。

#### 第 1 次课：DNN 基础架构与计算特征（3 课时）

| 项目 | 内容 |
|------|------|
| **核心问题** | DNN 在算什么？为什么它对硬件提出了全新要求？ |
| **课时 1：从神经元到深度网络** | 神经元与 MLP、激活函数、反向传播的直觉（不推完整公式）；训练与推理的计算差异 |
| **课时 2：算子族与计算特征** | 算子分类（MatMul / 矢量 / 归约 / Elementwise）；计算密度、算力受限 vs 访存受限——Roofline 直觉 |
| **课时 3：数据流与复用** | 权重 / 激活 / 梯度的数据量级；批处理与数据复用——为 NPU 数据通路设计埋伏笔 |
| **课堂互动与产出** | 小组完成一张《算子-硬件诉求对照表》：第一部分结束时的累积产出物（每次课补充） |

#### 第 2 次课：CNN 与 Transformer 的算法细节（3 课时）

| 项目 | 内容 |
|------|------|
| **核心问题** | 两代主流网络的算法细节，各自向硬件要什么？ |
| **课时 1：CNN 细节** | 卷积 / 池化 / BN、感受野与多层堆叠；im2col：卷积如何化为 GEMM |
| **课时 2：Transformer 细节** | QKV 注意力与多头机制、残差与 LayerNorm、KV Cache、MoE 概览 |
| **课时 3：计算结构对比** | 局部窗口复用（CNN）vs 全局注意力（Transformer）；Prefill / Decode 两阶段的算力-访存特征——各自对 NPU 的核心诉求 |
| **课堂互动与产出** | 补充《算子-硬件诉求对照表》（卷积 / 注意力两列） |

#### 第 3 次课：DNN 量化原理（3 课时）

| 项目 | 内容 |
|------|------|
| **核心问题** | 少几位比特，精度损失多少、收益多大？ |
| **课时 1：数值表示与定点化** | FP32 / FP16 / BF16 / INT8 / FP8：动态范围与精度的权衡；定点化直觉 |
| **课时 2：量化方法** | per-tensor / per-channel、对称 / 非对称量化；校准与量化误差、PTQ vs QAT |
| **课时 3：缩放因子与块量化** | MX 块量化（每 32 元素共享 scale）——为第二部分 NPU MX 矩阵计算埋伏笔；量化收益的电路直觉：位宽减半 ≈ 面积功耗约降 1/4 |
| **课堂互动与产出** | 手算一个 per-channel 量化例子并估计误差上界 |

#### 第 4 次课：DNN 模型压缩与硬件感知优化（3 课时）

| 项目 | 内容 |
|------|------|
| **核心问题** | 压缩-精度-延迟三角，怎么权衡？ |
| **课时 1：压缩方法族** | 剪枝（非结构化 / 结构化）、知识蒸馏、低秩分解——各自的硬件可兑现性 |
| **课时 2：量化感知训练与混合精度** | QAT 流程、敏感层分析、精度-压缩率权衡 |
| **课时 3：硬件感知优化** | 硬件感知 NAS 一瞥；压缩-精度-延迟三角的决策框架——收口："压缩收益要在真实硬件上兑现，怎么兑现？看第二部分" |
| **课堂互动与产出** | 完成《算子-硬件诉求对照表》终版（含量化行），作为第二部分的输入 |

### 第二部分：Ascend C 加速 DNN 核心计算（9 课时 · 3 次课详案）

> 三次课递进：**矩阵编程（Tensor API 工具基座）→ 量化（矩阵的低比特变体＋大作业预演）→ 卷积与注意力（矩阵在网络结构上的应用）**；第一部分的《算子-硬件诉求对照表》在每次课被逐行"兑现"。

#### 第 5 次课：Ascend C Tensor API 矩阵编程（3 课时 · 详细介绍）

| 项目 | 内容 |
|------|------|
| **核心问题** | 怎么用 Tensor API 亲手把矩阵计算交给 Cube？ |
| **课时 1：Tensor 编程范式** | 异构编程模型（Host / Device、核函数定义与调用）；**Tensor 为一等公民**：GlobalTensor / LocalTensor（GM 与片上存储的张量视图）、DataCopy 数据搬运、Tensor API 编程的典型流程 |
| **课时 2：Layout 与矩阵数据布局编程** | Layout 抽象与布局代数（解耦 / 组合 / 移植）；NZ / ZZ 分形布局的 Tensor 视角；用 Tensor API 组织矩阵搬运（Nd2Nz DataCopy）——**Cube 数据通路（GM→L1→L0A/L0B→L0C→GM）逐段亲手编排** |
| **课时 3：矩阵计算编程实践 ＋ SIMD/SIMT 混合编程介绍** | 基于 Tensor API 手写 GEMM 核心流程：分块搬运 → 分形加载 → 矩阵计算 → 结果写回；Tiling 切分与多核均衡；GEMM 跟练 → 独立实现（在线 Notebook）；**SIMD/SIMT 混合编程介绍**——AIV 侧 Vector Function 编程形态、SIMD 与 SIMT 协同的典型场景 |
| **课堂互动与产出** | **《我的第一个矩阵算子》＋ Tiling 账本**（选型理由 + 估算数据 + 实测对照）；组间对比"谁的 Tiling 更接近理论搬运量" |

#### 第 6 次课：Ascend C 加速 DNN 核心计算——量化（3 课时 · NPU 量化详细介绍）

| 项目 | 内容 |
|------|------|
| **核心问题** | 第一部分学的量化原理，落到 NPU 算子上怎么做、怎么快？ |
| **课时 1：NPU 量化详解 I——数据通路** | int8 分形布局、per-channel / MX 缩放因子的 Cube 支持（呼应第一部分第 3 次课 MX 原理）；量化-计算-反量化的融合形态 |
| **课时 2：NPU 量化详解 II——量化矩阵乘案例拆解** | 量化数据布局、scale 因子的数据通路、Mmad 组织与反量化融合——**结业大作业 `quant_matmul` 的完整预演** |
| **课时 3：fp4 量化实践案例** | FP4 低比特格式与块缩放（MXFP4）；昇腾低比特格式演进（INT8 → HiF8 → FP4）；fp4 量化推理实践案例（结合 [cann-recipes-infer](https://gitcode.com/cann/cann-recipes-infer) 低比特部署样例）；int8 / fp16 / fp4 性能对比——用第一部分"位宽红利"定量解释 |
| **课堂互动与产出** | **《量化算子预演笔记》**（数据通路图 + 多精度对比数据）——直接衔接结业大作业 |

#### 第 7 次课：Ascend C 加速 DNN 核心计算——卷积与注意力（3 课时 · NPU 卷积详细介绍）

| 项目 | 内容 |
|------|------|
| **核心问题** | 第一部分画的卷积 / 注意力数据流，在 NPU 上怎么落地？ |
| **课时 1：NPU 卷积详解 I——Cube 映射** | im2col+GEMM 路线（展开开销 vs 复用收益）vs 直接卷积（分形供给）；卷积参数（N/C/H/W/K）到 Tiling 的映射 |
| **课时 2：NPU 卷积详解 II——案例与优化** | 真实 Conv2D 算子剖析：多核均衡、双缓冲、Bank 供给；卷积跟练 → **改造实验**（调 Tiling / 对比布局），记录性能变化并用原理解释 |
| **课时 3：注意力加速** | QKV = Batch MatMul、Softmax 归约的 Vector 通路；FlashAttention 融合思想：分块在线 softmax，减少 HBM 读写——融合是 NPU 上注意力加速的主线 |
| **课堂互动与产出** | **《卷积改造实验记录》**（"参数—性能—原理"三栏对照表，至少 3 组实验） |

### 第三部分：实践与内容拓展（建议 6 课时+）

| 模块 | 内容 | 产出 |
|------|------|------|
| **`quant_matmul` 结业大作业**（核心） | 开发与 **Qwen3-1.7B 大模型匹配**的量化矩阵乘算子 `quant_matmul`：功能跑通（判题）→ 微结构剖析 → 可选 PyTorch 集成与持续优化（详见第五章） | 大作业各档产出 |

## 五、结业作业

### 5.1 结业大作业：`quant_matmul`（参考启航营两周课程结业结构 · 单算子）

> 大作业选定与 **Qwen3-1.7B 大模型匹配**的矩阵算子 **`quant_matmul`**（量化矩阵乘：低比特 A/B 矩阵 + 缩放因子）——它是本课知识的"会师点"：**量化原理**（第一部分第 3~4 次课）、**Tensor API 矩阵编程**（第 5 次课）、**量化数据通路与 fp4 案例**（第 6 次课完整预演）。作业结构参考 [启航营（两周）](../01_bootcamp/syllabus_two_weeks_bootcamp.md) 结业大作业（双算子版），本课**只保留 `quant_matmul` 单算子**，并增设数字系统设计特色考核（第二部分微结构剖析）。

| 作业 | 档位 | 内容 | 考核点 |
|------|------|------|--------|
| 三份课堂产出物 | **必选**（当堂） | Tiling 账本（第 5 次）、量化预演笔记（第 6 次）、卷积改造实验记录（第 7 次） | 实现正确性与"参数—性能—原理"对照解释 |
| **大作业 · 第一部分 功能跑通** | **必选** | 开发与 **Qwen3-1.7B 大模型匹配**的 **`quant_matmul`** —— 功能跑通 | CANNJudge 判题通过（正确性 + 性能不低于参考 80%） |
| **大作业 · 第二部分 微结构剖析** | **必选**（本课特色） | 剖析 `quant_matmul`：int8 量化数据布局与分形组织、缩放因子的数据通路、Mmad 组织与 UB Bank 搬运、双缓冲使能情况（msprof 流水图佐证）；可用 Verilog 辅助建模关键通路 | 剖析报告的电路层准确性与证据完整性（波形 / 流水图 / 指令流） |
| 大作业 · 第三部分 PyTorch 集成 | 可选加分 | 将 `quant_matmul` **接入 PyTorch 模型**（Qwen3-1.7B 匹配） | 单算子调用正确性 + 入图端到端验证 |
| 大作业 · 第四部分 持续优化 | 可选加分 | **持续优化** `quant_matmul`，提升推理性能 | 性能提升幅度 + 优化路径剖析（profiling 数据 + 改动说明；**每项优化须注明对应的原理依据**，如双缓冲 → 流水重叠、量化布局 → Bank 供给、位宽 → 带宽减半） |
| 期末考试综合题 | **必选** | 5~10 分：量化误差分析题、Tiling 选择分析题、卷积 Cube 映射题、微结构与流水图对应题（读图不写码） | 数字系统设计知识与 CANN 融合 |

## 六、学习建议

- **"翻译"习惯**：第一部分每个算法都问一句"它要硬件做什么"，并记入《算子-硬件诉求对照表》——第二部分每次课都在兑现这张表；
- **第 5 次课是基座**：Tensor API 矩阵编程是量化与卷积、注意力加速的工具前提，GEMM 独立实现务必亲自完成，不要止步跟练；
- **量化课早衔接大作业**：第 6 次课的量化矩阵乘预演与 fp4 案例即 `quant_matmul` 大作业的"彩排"，课上产出的数据通路图与多精度对比可直接用于大作业剖析报告；
- **先算账、再动手**：Tiling 选型、量化收益先动笔估算，再用实测对照——两处差距正是理解硬件的入口；
- **优化要有双证据**：每次性能改动都要"profiling 数据 + 原理依据"成对出现，形成"测量 → 分析 → 优化 → 验证"闭环；
- **学有余力**：完成可选作业后，可衔接 [01_bootcamp](../01_bootcamp/README.md) 启航营进入 Ascend C 算子开发实战。
