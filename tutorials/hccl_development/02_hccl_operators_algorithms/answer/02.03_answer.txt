========================================
1、答：正确。Full-mesh 下任意两点都直连，所有人可以同时互相交换，所以 1 步完成。
2、答：Ring 是 N-1 步；Halving-Doubling 是 log₂N 步，访问步长按 2^k（1、2、4、8……）增长。
3、答：① 流量规划：上万张卡同时发数据会互相争抢、链路拥塞，算法把一次通信拆成若干步，
   让每一步的数据量与链路使用可控；② 拓扑适配：Star / Tree / Full-mesh / Fat-Tree 各不
   相同，没有一种固定走法在所有拓扑上都高效。
4、答：错误。每一步交换的「距离」是翻倍的：第 1 步距离 1，第 2 步距离 2，第 3 步距离 4……
5、答：C。块到达一个 Rank 后会和该 Rank 的本地块做归约（按元素相加），内容越滚越多，
   所以标签会从 P1 变成 P1+P2、再变成 P1+P2+P3。
6、答：B。Mesh 要求任意两个 Rank 之间都有直连链路（Full-mesh），对拓扑要求最高。
7、答：错误。算法必须和拓扑匹配：拓扑越好、规模越大，越倾向于用步数更少的算法；
   拓扑受限时 Ring 反而更可靠。
8、答：Ring 要 N-1 = 7 步；Halving-Doubling 只要 log₂8 = 3 步。说明规模越大，两者的步数
   差距越显著——这正是 Halving-Doubling 在大规模集群上更优的原因。
