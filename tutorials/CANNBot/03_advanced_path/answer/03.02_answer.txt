03.02《多维度调试》练习答案

1.（单选题）B
   解析：症状三问定类：能跑完（排除 ④）、无错误码
   （排除 ②）、结果特定输入域超差（③ 精度类）；再按
   深度分层：diff 刚超 atol 一点点且 100% 集中负值带，
   指向指令层（Tanh ~1 ulp 绝对误差 × Step6 抵消放大，
   真机 189 个超差元素）。C 错：算法层（分段缺失）的
   特征是饱和区问题，而失败集中在 |x|<6；A/D 与签名
   不符。

2.（多选题）B、C
   解析：B 是设计内教学点，4 个失败全在 |x|<6 负值带，
   分段（|x|>6）根本不触碰，"分层修复不是一修全绿"；
   C 是分段的真实收益：饱和区从"依赖 x³ 溢出与 tanh
   饱和语义碰巧正确"变为"构造性正确"。A 错（修复本身
   是对的）；D 错（gelu naive kernel 无 Compare 调用，
   坑 2 是 xlog1py 实录走读，不是本工程失败的原因）。

3.（简答）参考要点
   - golden 参考链在 x=−Inf 处：inner 与 tanhIn 均为
     −Inf，tanh(−Inf)=−1，z = 0.5·(−Inf)·(1−1) =
     (−Inf)·0 = **NaN**，参考实现给出的就是 NaN，
     而非数学上的 0；
   - 分段负侧若写字面 0：x=−Inf 时 impl=0 ≠ golden=
     NaN，L2-2 **新增**失败（真机验证过的隐藏考点）；
   - 0·x 构造：有限负值 → ∓0（保号）；x=−Inf →
     0·(−Inf)=NaN，与 golden 语义逐点一致；
   - 一般教训：分段策略必须对照 golden 的特殊值行为
     设计，不能只看数学极限。数学正确之外还有
     "参考语义正确"。

4.（编程实践·必做）修复顺序倒置实验 参考要点
   - 预期结果（对照 FACTS.md 验证矩阵）：先单独应用
     fix3_sigmoid → 黑盒 14/14 全绿（sigmoid 恒等式
     单独修复即全绿，它修复的是全部 4 个失败的真凶）；
     叠加 fix1_segmentation → 仍 14/14，终态与 FACTS
     的"双修复"一致；
   - 顺序为什么不影响终态：两个修复相互独立，分段
     修复的是饱和区（|x|>6，本就没有失败用例），sigmoid
     修复的是负值带精度（4 个失败的全部根因）；
   - 顺序为什么影响中间观察：先分段会经历"修复后失败
     集不变"的空转，这正是课上"分层修复不是一修全绿"
     教学点的现场复现；先 sigmoid 则一步到位，看不到
     这个现象；
   - 记录要求：每步的失败用例集（pytest 输出）+ 一段
     "顺序与观察"的因果解释，这是产物 ② 证据链的
     延伸。

5.（编程实践·选做）一招见效的检验用例 L2-6 参考要点
   - 设计推理（值得先想清楚再动手）：区分"分段正确
     （0·x）"与"分段缺失且负侧字面 0"：
     · x=−Inf：正确 → NaN（0·(−Inf)）；字面 0 → 0
       vs golden=NaN → **显形**，这是唯一可靠的区分点；
     · 有限大负值（如 x=−100）：golden 链式 z_true 下
       溢为 ∓0，字面 0 给 +0。若断言把 ±0 视为相等，
       此处不显形；
     · [-6,-3] 带：两种实现都走计算链，不区分；
   - 参考数据：x = [−Inf, −100, −6, −5.1, −3, ±0, 3,
     5.1, 6, 100, +Inf, NaN]（覆盖 ±Inf、有限大负、
     负值带、正饱和、特殊值）；
   - 预期区分逻辑：对 x=−Inf 断言 isnan(impl) 与
     isnan(golden) 同真；对 NaN 输入断言 NaN 传播；
     其余按容差；
   - 教训沉淀：能区分两个实现的用例才是有效用例，
     "边界用例是唯一防线"（基础课程 02.03）的调试版。
