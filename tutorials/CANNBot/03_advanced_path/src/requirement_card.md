# Lab A 需求卡：gelu_approx（模块一 · 算子生成）

> 这是你在本 Lab 要交给 CANNBot 完整版工作流的需求。请先通读并理解每一条。

## 算子定义

- **公式**：`z = gelu_approx(x) = 0.5 · x · (1 + tanh(√(2/π) · (x + 0.044715x³)))`，逐元素一元运算
- **精度红线**：朴素实现中 `x + 0.044715x³` 在 `|x| > 15` 时中间值溢出 fp32（x³ > 3375 · 0.044715 ≈ 150.9，乘以 x 后超 2263，与 `√(2/π)` 相乘后超 1806（fp32 上限约 3.4e38 本身不溢出，但精度损失不可忽略））；`tanh` 在大参数下饱和为 ±1，需确保饱和区行为正确（z → x 或 z → 0）
- **为什么选这个算子**：GELU 是 LLM FFN 层的核心激活函数，8 步计算链（Mul→Mul→Add→Mul→Tanh→Add→Mul→Mul）远比 xlog1py 的 3 步复杂，每一步的舍入误差都可能累积

## 精度要求（口径前置声明）

1. **Golden**：numpy float64 的精确 GELU：`0.5 * x * (1 + np.tanh(np.sqrt(2/np.pi) * (x + 0.044715 * x**3)))`，fp32 输入无损上转、舍回 fp32 比对
2. **验收容差**：逐元素 rtol = 1e-5，atol = 1e-7
3. **特殊值比对**：NaN 位置逐一相等；±Inf 同号同位置；z 在 x→+∞ 时应趋于 x，x→-∞ 时趋于 0
4. **实现红线**：
   - 朴素 `x**3` 在大 x 时中间精度损失不可忽略，**必须做缩放或分段**（|x| > 阈值时直接 z = x 或 z = 0，避免多项式溢出）
   - tanh 的向量指令精度需查表确认，必要时用 `2·sigmoid(2y)-1` 恒等式替代
