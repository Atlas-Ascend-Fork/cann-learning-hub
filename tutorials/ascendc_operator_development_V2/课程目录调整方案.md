# 课程目录调整方案

本轮整理前置章节 Basic Overview、L4-01 至 L4-03、L4-05 至 L4-08、L4-10 至 L4-16。V2 将 Memory 与 Reg 矢量算子编程合并为 L4-03，并增设 L4-16 高级特性。课程目录参考[原子课程目录规划](/home/zyx/cann-learning-hub_A3/standard_course/00_atomic_courses/directory.md)，下表以完整文件名链接到对应的 V2 Notebook。V2 以昇腾 950 为主，原规划要求覆盖 A2/A3 与 950；表中归属依据是教学内容，跨平台适用性需按样例核对。

## 新章节的统一要求

每个调整后的章节（含 Basic Overview 和 Quick Start）都按「章节导读 → 正文课节 → 全章综合练习」组织。

- **章首导读（Chapter Intro）** 放在第一节，说明本章学习目标、所需基础和课节安排。
- **全章综合练习** 放在最后一节，围绕本章学习目标设计任务或问题，让学习者综合运用各节的核心内容。
- **配套资源引用** 移动或重命名课节时，同步更新 Notebook、README 和脚本中指向配图（`image/` 或 `images/`）、源码（`src/`）和参考答案（`answer/`）的相对路径。调整后逐章检查图片能否显示、源码能否按代码中的路径读取、答案链接能否打开。

整理各章时，可按新章节范围改编已有导读、章节测试或实践 Notebook；缺少的导读或综合练习须补写。
